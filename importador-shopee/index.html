📦 Importador de CSV da Shopee

Envie o arquivo que a Shopee gera com os links de afiliado, e a ferramenta monta tudo pronto pra colar no seu projeto — busca a foto de cada produto automaticamente.

⚠️ Essa página só gera o arquivo atualizado pra você baixar. Ela não publica nada sozinha — depois de baixar, é o mesmo processo de sempre: colar na pasta do projeto, git add -A, git commit, git push.

1. Categoria desses produtos

Escolha a categoria que se aplica à maioria dos produtos desse CSV (dá pra editar produto por produto depois, pelo painel).

2. Envie o arquivo CSV

O arquivo que a Shopee te dá quando você seleciona produtos e gera os links (tem colunas como "Item Name", "Price", "Offer Link").

3. Buscar fotos e montar o arquivo

Isso demora alguns segundos por produto (precisa visitar a página de cada um pra pegar a foto). Não feche essa aba enquanto estiver rodando.

4. Conferir e baixar
